# sophialaboyrie.com

Plain HTML, CSS and JavaScript portfolio. No build step.

## Preview

Open `index.html` in your browser (double-click it).

## Edit content

- **Case studies:** edit `js/case-studies.js`. Copy a block, change the text. Instructions are at the top of that file. Cards and pages are generated automatically.
- **Intro, about, contact:** edit `index.html`.
- **Images:** put them in an `images/` folder and reference them in the case study with `image` and `imageAlt`.
- **Colours and fonts:** the variables at the top of `css/styles.css`.

## Publish later (GitHub Pages)

Push to GitHub, enable Pages on the `main` branch, and keep the `CNAME` file so the custom domain works.
